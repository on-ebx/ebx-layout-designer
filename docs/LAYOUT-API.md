# Layout API

The design note that lived here (2026-10-12, for the MDM Factory's accelerators) is closed: the endpoint it asked for is the
JSON-RPC MCP endpoint built in 1.21.0, for record forms and explorers. Read **[MCP.md](MCP.md)** for the tools, the transport
and the rights, **[LAYOUT-FORMAT.md](LAYOUT-FORMAT.md)** and **[EXPLORER-FORMAT.md](EXPLORER-FORMAT.md)** for the JSON a layout
or an explorer holds, and **[OPERATIONS.md](OPERATIONS.md)** for the settings, logs and codes of a running module.

Not built (never asked again since): an in-JVM contract between modules (MBean) and a `layout_declare` tool.
